# Help

## Country Series Practice

Practice country-related words (country name, language, adjective, person) grouped by country. Open this page from Series Practice → Country.

### Settings

Choose an answer-field preset (Basic / Common / Full), or expand custom checkboxes. You can also allow temporary answer reveal.

### Questions

Each country is one block titled with the country name (Chinese UI uses Chinese; English UI uses English). Entries sharing that country’s tag appear inside the block. Prompts are typically Chinese, English, and part of speech.

* Click **Check** at the bottom to grade answers
* Fully correct entries (under selected answer fields) leave the block

### Flow control

* **Finish**: merge this round into the summary
* **Restart**: clear inputs; keep temporary scores
* **Abort**: discard temporary scores and return to series select
