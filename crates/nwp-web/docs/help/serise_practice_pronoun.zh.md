# 使用说明

## 代词系列练习

本页练习挪威语代词在不同形式上的拼写。进入前请从「单词系列练习」页选择「代词」。

### 题目分组

页面按人称/指示代词分成三组，每组可单独「检查本组」：

1. **我 / 你 / 他 / 她**：主格、宾格、所有格（阴阳/中性/复数）、反身、反身物主等形式
2. **我们 / 你们 / 他们 / 她们**：对应复数人称形式
3. **这 / 那 / 这些 / 那些**：指示代词相关形式

每个输入框对应一种语法形式，按提示填写即可。

### 作答与检查

填写后点击该组的「检查本组」。可重复检查并累计本轮对错。若词库缺少映射词条，控制台会提示。

本页不会在答对后自动换题，适合集中攻克一整张代词表。

### 流程控制

* **完成练习**：合并本轮成绩并进入练习总结
* **重新练习**：清空当前作答状态，保留本轮临时成绩
* **放弃练习并返回**：清空临时成绩，返回单词系列选择页

左上角也可返回系列选择页。
