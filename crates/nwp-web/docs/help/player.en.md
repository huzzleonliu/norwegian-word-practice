# Instructions

## Read along

This page plays audio next to lyrics so you can follow along. Open a local folder, choose files, or load a built-in book such as Byen Er Bergen.

* Audio and lyrics are paired by filename. Same-timestamp lines become source and translation.
* Click a lyric line to jump there. Use the transport buttons to move between lines, change speed, or loop the current line.
* Built-in books are loaded from `data/audio`. You can also drop audio and `.lrc` / `.srt` files onto the page.

Use **Back** to return to the practice mode page.
