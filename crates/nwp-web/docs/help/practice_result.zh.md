# 使用说明

## 练习总结

完成本轮练习后会进入本页，用于查看准确率、错题，并可选导出结果或继续练习。

### 本次练习结果

显示本轮总体准确率，以及本轮错过的词条明细，通常包括：

* 中文提示
* 词性
* 正确答案
* 你的错误回答

准确率按各字段「正确次数 /（正确 + 错误）」统计。

### 历史数据与总数据

* **历史数据（不含本次）**：进入本轮之前的累计成绩
* **总数据（含本次）**：把本轮合并进去之后的累计成绩

方便对比这一轮练习带来的变化。

### 流程控制

* **导出练习结果**：把结果导出为 `.pracresult` 文件（浏览器环境），文件名通常带日期
* **继续练习**：清空本轮临时结果，返回刚才完成练习时设定的练习页，接着练

左上角「返回上一级页面」也会回到对应练习页（词库练习，或某个单词系列练习页），具体取决于你是从哪一类练习完成进来的。

中间控制台会显示本次准确率，以及导出/继续等操作状态。
