# Instructions

## Practice Summary

After you finish a practice session, this page shows accuracy and mistakes, and lets you export results or continue practicing.

### Current Session Result

Shows overall accuracy for this session and a list of missed entries, typically including:

* Chinese prompt
* Part of speech
* Correct answer
* Your incorrect answer

Accuracy is computed per field as correct / (correct + wrong).

### History and All Data

* **History (excluding current)**: cumulative scores from before this session
* **All Data (including current)**: cumulative scores after merging this session

This makes it easy to see what this round changed.

### Flow Control

* **Export Practice Result**: download a `.pracresult` file in the browser (usually dated in the filename)
* **Continue Practice**: clear temporary session results and return to the practice page that led here

**Back to previous page** also returns to the matching practice page (lexicon practice or a series practice page), depending on which mode you finished.

The console shows this session’s accuracy and status for export/continue actions.
