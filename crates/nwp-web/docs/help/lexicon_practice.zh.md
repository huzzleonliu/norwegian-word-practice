# 使用说明

## 词库练习

本页对你在选词页确认选中的单词进行拼写/变形练习。你可以配置题目提示字段、需要回答的字段，以及每页题目数量。

### 第一部分：练习设置

* **一页练习**：控制当前页同时出现多少道题
* **根据**：选择题目展示用的提示字段（例如中文、英文等）
* **回答**：勾选需要填写的挪威语字段（基础形、以及动词/名词/形容词等变形组）
* **答案显隐**：是否允许临时查看参考答案，也可一键隐藏已显示的答案

请至少勾选一个回答字段，否则无法正常作答。

### 第二部分：练习题

每道题根据设置显示提示，并提供对应输入框。

* 填写后点击「检查」判题
* 一道题中所有勾选的回答字段都正确，才算通过；通过后该题会离开当前页，并自动补入新题
* 若开启答案显隐，可临时显示参考答案帮助核对

判题时会做一定规范化比较（例如大小写、部分挪威语特殊写法），但仍以正确拼写为目标。

### 第三部分：流程控制

* **完成练习**：把本轮临时成绩合并进累计结果，并进入练习总结页
* **重新练习**：清空当前页作答状态，但保留本轮已累计的临时成绩，继续练
* **放弃练习并返回**：清空本轮临时成绩，返回选词页

左上角可返回选词页。中间控制台会显示可练习条数、本轮统计与检查状态。
