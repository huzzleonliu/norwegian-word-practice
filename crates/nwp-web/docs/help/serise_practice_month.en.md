# Instructions

## Month Series Practice

Practice spelling month-related Norwegian vocabulary. Enter via **Month** on the series selection page.

### Questions

Prompts are usually Chinese/English; answer with the Norwegian base form (`base_form`). Multiple questions appear per page (about 20 by default).

* Click **Check** to grade
* When all answer fields are correct, the question leaves the page and a new one is filled in automatically

### Flow Control

* **Finish Practice**: merge session scores and open the practice summary
* **Restart**: clear current page inputs/pass state, keep temporary session stats
* **Abort and Return**: clear temporary stats and return to series selection

The top-left control also returns to series selection. The console shows practice status and check results.
