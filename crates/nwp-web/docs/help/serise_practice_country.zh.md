# 使用说明

## 国家系列练习

本页按国家分组练习相关词汇（国名、语言、形容词、国人）。进入前请从「单词系列练习」页选择「国家」。

### 练习设置

顶部可选择回答字段预设（基础 / 常用 / 全面），也可展开自定义勾选要作答的形态字段。可开启临时显示参考答案。

### 练习题

每个国家为一块，大标题为国家名（中文界面显示中文名，英文界面显示英文名）。块内列出该国 tag 下的相关词条；提示通常为中文、英文与词性。

* 填写后点击页面下方「检查」判题
* 某词条在所选回答字段上全部正确后，会从当前块中移除

### 流程控制

* **完成练习**：合并本轮成绩并进入练习总结
* **重新练习**：清空作答状态，保留本轮临时成绩继续练
* **放弃练习并返回**：清空临时成绩，返回单词系列选择页
