# 使用说明

## 月份系列练习

本页练习挪威语月份相关词汇的拼写。进入前请从「单词系列练习」页选择「月份」。

### 练习题

题目通常以中文/英文为提示，要求填写对应的挪威语基础形（`base_form`）。每页会展示多道题（默认约 20 道）。

* 填写后点击「检查」判题
* 全部回答字段正确后，该题会离开当前页并自动补入新题

### 流程控制

* **完成练习**：合并本轮成绩并进入练习总结
* **重新练习**：清空当前页作答状态，保留本轮临时成绩继续练
* **放弃练习并返回**：清空临时成绩，返回单词系列选择页

左上角也可返回系列选择页。控制台会显示练习状态与检查结果。
