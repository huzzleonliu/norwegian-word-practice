# Instructions

## Number Series Practice

Practice Norwegian cardinal and ordinal number spelling. Enter via **Number** on the series selection page; the series lexicon loads automatically.

### Question Groups

Questions are split into three groups. Each group has its own **Check Group** button:

1. **1–20**
2. **21–30**
3. **40–100000 (Selected)**: common round tens/hundreds/thousands, not every consecutive number

Each row usually has: Arabic numeral prompt, cardinal input, ordinal input.

### Answering and Checking

Fill the fields, then click **Check Group** for that block. You can check repeatedly; correct/wrong counts add to this session’s temporary score. Missing lexicon entries are reported in the console.

Unlike lexicon practice, correct answers do not auto-replace with new questions—you can keep editing the same group.

### Flow Control

* **Finish Practice**: merge session scores and open the practice summary
* **Restart**: clear current inputs, but keep temporary session stats
* **Abort and Return**: clear temporary stats and return to series selection

The top-left control also returns to series selection.
