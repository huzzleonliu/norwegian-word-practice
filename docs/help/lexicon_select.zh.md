# 使用说明

## 选择练习单词

本页用于从当前已加载的词库中，挑选接下来要练习的单词。进入本页前，请先在「练习模式选择」页加载或导入词库。

### 当前词库状态

页面上方会显示当前词库来源与词条数量。若提示尚未加载词库，请返回练习模式选择页完成加载或导入。

### 搜索与筛选

使用搜索面板可以按关键字查找单词，并勾选参与搜索/显示的列（如中英文翻译、词性、标签、各类变形字段等）。

* 可展开列范围，按基础组、动词/名词/形容词等分组勾选列
* 支持「全选列」「全不选列」
* 表格支持按列排序、调整列宽，以及分页浏览

### 勾选单词

在表格中勾选想练习的词条（支持拖拽批量勾选）。勾选后需要点击表格区域的「确认修改」，才会把选择写入当前词库。

* 「全选」「全不选」作用于当前筛选可见的行
* 未点击「确认修改」时，下方「开始练习」不会使用你刚勾选但未确认的草稿

### 开始练习

确认至少选中一条词条后，点击「开始练习」。系统会对选中词条随机打乱顺序，然后进入词库练习页。

左上角可返回练习模式选择页。
