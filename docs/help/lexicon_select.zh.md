# 使用说明

## 选择练习单词

本页用于从当前已加载的词库中，勾选接下来要练习的单词，然后开始词库练习。进入前请先在「练习模式选择」页加载内置词库或导入 CSV。

### 当前词库状态

页面上方控制台会显示词库来源、词条数量，以及选词相关提示。若提示词库为空，请返回练习模式选择页完成加载或导入。

### 搜索与筛选

使用搜索面板按关键字查找，并勾选参与搜索 / 显示的列（中英文、词性、标签、各类变形等）。

* 可展开列范围，按基础组、动词 / 名词 / 形容词等分组勾选
* 支持「全选列」「全不选列」
* 表格支持按列排序、拖拽调整列宽、分页浏览

### 勾选单词（查询模式）

本页的词库浏览器为**查询模式**：主要用来勾选要练习的词条（一般不在此页改字段内容）。

* 勾选支持拖拽批量操作
* 「全选」「全不选」作用于当前筛选可见的行
* **勾选后必须点击「确认修改」**，选择才会写入当前词库

下方「开始练习」读取的是已提交词库中的勾选结果。若只改了表格勾选却未点「确认修改」，开始练习时不会用上这些草稿勾选。

### 导出 CSV

词库浏览器底部、「确认修改」左侧提供「导出词库 CSV」。

* 导出的是当前**已确认提交**的词库（含已确认的勾选状态）
* 若刚改过勾选，请先「确认修改」再导出

### 开始练习

确认至少选中一条词条后，点击页面下方的「开始练习」。系统会对选中词条随机打乱顺序，然后进入词库练习页。

左上角可返回练习模式选择页。
