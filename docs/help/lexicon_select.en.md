# Instructions

## Select Words to Practice

Use this page to pick which words from the currently loaded lexicon you want to practice next. Before entering this page, load or import a lexicon on the practice mode selection page.

### Current Lexicon Status

The top of the page shows the lexicon source and entry count. If it says no lexicon is loaded, go back to the practice mode page and load or import one first.

### Search and Filters

Use the search panel to find words by keyword, and choose which columns participate in search/display (translations, part of speech, tags, inflection fields, and more).

* Expand the column list and toggle groups such as base fields, verb/noun/adjective variants, etc.
* Use **Select all columns** / **Unselect all columns**
* The table supports column sorting, column resizing, and pagination

### Select Entries

Check the entries you want to practice (drag to multi-select). After checking, click **Confirm Changes** in the table area so the selection is written into the current lexicon.

* **Select All** / **Unselect All** apply to currently visible filtered rows
* Without **Confirm Changes**, **Start Practice** will not use unchecked draft selections

### Start Practice

After confirming at least one selected entry, click **Start Practice**. Selected entries are shuffled, then you enter the lexicon practice page.

Use the top-left control to return to the practice mode selection page.
