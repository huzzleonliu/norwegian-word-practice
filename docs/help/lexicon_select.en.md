# Instructions

## Select Words to Practice

Pick which words from the currently loaded lexicon to practice next, then start lexicon practice. Before entering this page, load a built-in lexicon or import a CSV on the practice mode selection page.

### Current Lexicon Status

The console at the top shows the lexicon source, entry count, and selection hints. If the lexicon is empty, go back to the practice mode page and load or import one first.

### Search and Filters

Use the search panel to find words by keyword and choose which columns participate in search/display (translations, part of speech, tags, inflection fields, and more).

* Expand the column list and toggle groups such as base fields, verb/noun/adjective variants, etc.
* Use **Select all columns** / **Unselect all columns**
* The table supports column sorting, column resizing, and pagination

### Select Entries (Query Mode)

The lexicon browser on this page runs in **query mode**: mainly for choosing practice entries (not for editing field values here).

* Drag to multi-select checkboxes
* **Select All** / **Unselect All** apply to currently visible filtered rows
* After checking, you **must click Confirm Changes** so the selection is written into the current lexicon

**Start Practice** reads the committed lexicon selection. Draft checks that were not confirmed are ignored.

### Export CSV

**Export Lexicon CSV** sits at the bottom of the lexicon browser, to the left of **Confirm Changes**.

* Export uses the **committed** lexicon (including confirmed selection flags)
* If you just changed checks, click **Confirm Changes** before exporting

### Start Practice

After confirming at least one selected entry, click **Start Practice** at the bottom. Selected entries are shuffled, then you enter the lexicon practice page.

Use the top-left control to return to the practice mode selection page.
