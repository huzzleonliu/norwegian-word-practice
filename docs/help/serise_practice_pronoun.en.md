# Instructions

## Pronoun Series Practice

Practice Norwegian pronoun forms. Enter via **Pronoun** on the series selection page.

### Question Groups

Questions are split into three groups. Each group has its own **Check Group** button:

1. **I / You / He / She**: nominative, accusative, possessive (m/f/n/pl), reflexive, reflexive possessive, etc.
2. **We / You(pl) / They(m) / They(f)**: plural person forms
3. **This / That / These / Those**: demonstrative-related forms

Each input corresponds to one grammatical form—fill according to the prompts.

### Answering and Checking

Fill the fields, then click **Check Group**. You can check repeatedly; scores accumulate for the session. Missing mapped entries are reported in the console.

Correct answers do not auto-replace with new questions—this layout is meant for working through the full pronoun table.

### Flow Control

* **Finish Practice**: merge session scores and open the practice summary
* **Restart**: clear current inputs, keep temporary session stats
* **Abort and Return**: clear temporary stats and return to series selection

The top-left control also returns to series selection.
