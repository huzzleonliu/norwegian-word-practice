# 使用说明

## 数词系列练习

本页练习挪威语基数词与序数词的拼写。进入前请从「单词系列练习」页选择「数词」，系统会自动加载系列词库。

### 题目分组

页面按数字范围分成三组，每组可单独「检查本组」：

1. **1–20**
2. **21–30**
3. **40–100000（精选）**：覆盖常见整十、整百、整千等精选数字，并非连续全部数字

每一行通常包含：阿拉伯数字提示、基数词（cardinal）输入框、序数词（ordinal）输入框。

### 作答与检查

填写后点击该组的「检查本组」。可重复检查；正确与错误会计入本轮临时成绩。若缺少对应词条，控制台会提示缺失项。

本页不会像词库练习那样「答对后自动换题」，你可以反复修改同一组内容。

### 流程控制

* **完成练习**：合并本轮成绩并进入练习总结
* **重新练习**：清空当前作答状态，但保留本轮已累计的临时成绩
* **放弃练习并返回**：清空临时成绩，返回单词系列选择页

左上角也可返回系列选择页。
