# 使用说明

## 本地词库修改器

本页用于在浏览器中编辑本地词库：手动添加、AI/词典辅助填写、表格修改，以及 CSV 导入导出。页面上方的控制台会提示操作状态；改完表格后请先「确认修改」，再导出。

### 单条添加

按词性填写挪威语基础形与各类变形字段，以及中英文翻译、标签等，然后点击「添加单条」。

* 「清空」会重置当前单条表单（一般不影响已保存的词库 Token / 默认标签等设置）
* 添加成功后词条会直接写入当前词库

### 词典优先查询（Ordbok → Gemini）

用于根据挪威语词形自动补全字段：

1. 可配置 Gemini / Google Translate Token，并检测连通性
2. 输入要查询的词形，可选填写默认标签
3. 点击查询：优先走 Ordbok；必要时再用 Gemini 补全；Google Translate 常用于回填中英文
4. 「仅 Ordbok」可关闭 Gemini 回退

查询结果可能：

* 直接填入上方「单条添加」表单，或
* 分流到下方「多条添加」预览表（一词多义、多词性等情况）

### 多条添加

展示查询生成的多条预览。确认无误后点击「添加多条」一次性写入词库；也可勾选删除不需要的预览行，或「清空」预览区。

### 词库浏览器（编辑）

以表格方式查看和修改当前词库：

* 可编辑单元格内容
* 可勾选删除列（支持拖拽批量）
* 改完后必须点击「确认修改」才会真正应用删除、保存编辑并处理 id 等校验
* 支持搜索、列显示范围、排序、分页，用法与选词页类似

### 导入与导出

* **导入词库 CSV**：从本机导入，通常会覆盖当前词库
* **导出词库 CSV**：把当前词库下载为 CSV。导出前请确认表格改动已点过「确认修改」

左上角可返回练习模式选择页。本页不直接进入练习，编辑完成后请回到模式选择页加载/导入词库再练习。
