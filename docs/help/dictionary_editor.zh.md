# 使用说明

## 本地词库修改器

本页用于在浏览器中私人定制词库：单条添加、词典 / AI 辅助填写、多条预览写入，以及表格内编辑与导出。

### 进入条件

本页受 NFT 门禁保护：

* 未连接钱包时，会先触发「连接钱包」
* 已连接但不持有本系列 NFT 时，会在新标签页打开「铸造 NFT」页
* 连接钱包且持有本系列至少一枚 NFT 后，才能使用本页

可从「练习模式选择」页右下角的「本地词库修改器」进入；也可在地址栏打开 `/editor`（同样会经过门禁）。

### 页面结构概览

1. **状态控制台**：显示当前操作结果；并提醒表格改动需先「确认修改」再导出  
2. **单条添加**：手动填写一条词条  
3. **词典优先查询**：Ordbok → Gemini 等辅助补全，结果可进单条表单或多条预览  
4. **多条添加**：确认预览后批量写入  
5. **词库浏览器（编辑模式）**：表格改词、删词、搜索筛选；底部可导出 CSV  

词库会保存在浏览器本地（刷新后通常仍可恢复）。左上角可返回练习模式选择页。本页不直接开始练习。

### 单条添加

按词性填写挪威语基础形与变形字段，以及中英文翻译、标签等，然后点击「添加单条」。

* 「清空」重置当前单条表单（一般不影响已保存的 Token / 默认标签）
* 添加成功后词条会立即写入当前词库

### 词典优先查询（Ordbok → Gemini）

根据挪威语词形自动补全字段：

1. 可配置 Gemini / Google Translate Token，并检测连通性  
2. 输入要查询的词形，可选填写默认标签  
3. 点击查询：优先 Ordbok；必要时用 Gemini 补全；Google Translate 常用于回填中英文  
4. 「仅 Ordbok」可关闭 Gemini 回退  

查询结果可能：

* 直接填入上方「单条添加」表单，或  
* 分流到下方「多条添加」预览表（一词多义、多词性等）

### 多条添加

展示查询生成的多条预览。确认无误后点击「添加多条」一次性写入词库；也可勾选删除不需要的预览行，或「清空」预览区。

### 词库浏览器（编辑）

以表格查看和修改当前词库：

* 可编辑单元格；可勾选删除列（支持拖拽批量）
* **改完后必须点击「确认修改」**，删除与编辑才会真正写入词库，并完成 id 等校验
* 支持搜索、列显示范围、排序、拖拽调列宽、分页

### 导出加密词库（.nwpdict）

导出按钮在词库浏览器底部、**「确认修改」左侧**（编辑页底部不再提供导入入口；导入请到「练习模式选择」页）。

* 导出会生成加密词库文件（`.nwpdict`），不是明文 CSV
* 导出的是**已确认提交**的词库，不是未点「确认修改」的表格草稿
* 编辑或删除后，请先「确认修改」，再点「导出词库文件」

导出文件可在练习模式选择页用「导入词库文件」直接导入（系统会自动解密）；明文 CSV 仍兼容。
