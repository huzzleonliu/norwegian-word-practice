# Instructions

## Lexicon Practice

Practice spelling and inflection for the words you confirmed on the word-selection page. You can configure prompt fields, answer fields, and how many questions appear per page.

### Part 1: Practice Settings

* **Entries per page**: how many questions appear at once
* **Prompt field**: which fields are shown as the question prompt (e.g. Chinese, English)
* **Answer fields**: which Norwegian fields you must fill in (base form and verb/noun/adjective variant groups, etc.)
* **Answer Reveal**: whether you may temporarily show reference answers, and a control to hide revealed answers

Select at least one answer field, or you will not be able to practice properly.

### Part 2: Questions

Each question shows the prompt and input boxes according to your settings.

* Click **Check** to grade your answers
* A question counts as passed only when every selected answer field is correct; then it leaves the page and a new question is filled in automatically
* If answer reveal is enabled, you can temporarily show the reference answer

Grading applies light normalization (e.g. case and some Norwegian spelling variants), but correct spelling is still the goal.

### Part 3: Flow Control

* **Finish Practice**: merge this session’s temporary scores into the cumulative result and open the practice summary
* **Restart**: clear current inputs/pass state on this page, but keep temporary session stats and continue
* **Abort and Return**: clear temporary session stats and return to word selection

Use the top-left control to return to word selection. The console shows available entries, session stats, and check status.
