# Norwegian Word Practice

## service简介
这是一个辅助挪威语单词记忆的工具。基本功能是根据问题，输入挪威语答案，最终检验并修正错误。


## 基础功能
- 背单词功能
    - 根据中文写挪威语单词
    - 根据挪威语单词写中文
- 单词系列练习

## 详细功能

- 根据中文要写出挪威语的练习的时候，要根据词性，写出多种变形
    - 动词：原型（一般式），过去式，祈使式
    - 名词：原型（单数），复数，单数特指，复数特指
    - 形容词：原型（对应阴性/阳性），对应中性，对应复数，比较级，最高级泛指，最高级特指
    - 副词：原型（原级），比较级，最高级
- 根据中文要写出挪威语的练习的时候，遮挡住其他变形，也可以暂时亮出其他变形
- 根据中文要写出挪威语的练习的时候，显示对应的英文单词
- 根据中文要写出挪威语的练习的时候，记录错误的单词，做错题统计
    - 错的题的中文是什么，是哪种变形错的，错了几次，每次是怎么错的
- 单词系列根据系列随机挖空填词
    - 数词：基础数词，序数词
    - 月份
    - 代词：
        - 主格，宾格，所有格阴阳性，所有格中性，所有格复数，反身代词，反身物主代词
        - 我，我们，你，你们，他，他们，她，她们，这个，这些，那个，那些
    - 疑问词

## 交互流程
- 用户进入网页，导入练习结果（第一次使用可以不导入）
- 选择练习项目：背单词功能或单词系列练习功能，或者选择增删改查词库
- 如果是背单词功能：
    - 选择词库中的条目
        - 根据是否选中，词性，tag,或者中文/英文/挪威语的某一种形态，进行搜索/筛选
    - 进行练习
    - 练习完成后进入总结页面
- 如果是单词系列练习：
    - 选择练习的词种
    - 进行练习
    - 练习完成后进入总结页面
- 进入总结页面
    - 查看练习总结
    - 导出练习结果，保存到本地（这里的练习结果包含两个功能的练习结果，包含选择的词库条目）
- 词库修改页面
    - 单条添加或多条添加
    - 词库浏览器，负责删除或者更改值
    - 提交的时候需要对条目进行比对，除了序号不能重复以外，各个词性对应的形式必须添加完整，否则报错

## 数据结构设计
- 词库（表）
    - 手动控制数据库导入
    - 列名：
        - 序号（string，唯一，不可为空,string的值为原型对应的值，如果存在重复，那么就在值后面加上序号）
        - 是否选中（布尔，默认为是，不可为空）
        - 词性（“动词，名词，形容词，副词，基础数词，序数词，月份，代词，疑问词”中选1，不可为空）
        - tag（string数组，可为空，用来方便构建词库的时候搜索用，也方便按分组选中）
        - 对应英文（string数组,可为空）
        - 对应中文（string数组,不可为空）
        - 原型（string,不可为空）...（所有各种形式，使用的时候根据词性来选择）
        - 过去式（string,可为空）
        - 祈使式（string,可为空）
        - 复数（string,可为空）
        - 单数特指（string,可为空）
        - 复数特指（string,可为空）
        - 对应中性（string,可为空）
        - 对应复数（string,可为空）
        - 形容词比较级（string,可为空）
        - 形容词最高级泛指（string,可为空）
        - 形容词最高级特指（string,可为空）
        - 副词比较级（string,可为空）
        - 副词最高级（string,可为空）
- 练习结果（导入导出）
    - 项目：用户名（string），加密密钥（string），选择的词库条目（string数组），已练习的词库条目（表）
- 已练习的词库条目（表）
    - 列名：
        - 序号（string，和词库中的string保持一致）
        - 对应英文正确次数（usize,不可为空，默认为0），对应英文错误次数（usize,不可为空，默认为0），对应英文错法（string数组,可为空）
        - 对应中文正确次数（usize,不可为空），对应中文错误次数（usize,不可为空），对应中文错法（string数组,可为空，最大容量为5个string）
        - 原型正确次数（usize,不可为空），原型错误次数（usize,不可为空），原型错法（string数组,可为空，最大容量为5个string）
        - ...（所有各种形式的正确次数，错误次数和错法，使用的时候根据词性来选择）（usize,不可为空，默认为0）（usize,不可为空，默认为0）（string数组,可为空，最大容量为5个string）
- 练习结果（临时）：和练习结果“练习结果（导入导出）”相同，但是只用作导出的时候和原表merge用

## 运行流程
- 用户进入网页，导入练习结果（第一次使用可以不导入）
    - 解码导入的练习结果
        - ”*.pracresult”
    - 构建新的练习结果（临时表）
- 选择练习项目：背单词功能或单词系列练习功能
- 如果是背单词功能：
    - 从数据库中导入词库条目
        - 自动从服务器中下载临时词库
    - 选择词库中的条目
        - 只显示词性为动词，名词，形容词，副词的条目
        - 通过选择的条目的序号生成一个数组
    - 进行练习
        - 对所选条目序号的数组进行随机打散
        - 按打散后的顺序练习
        - 每次完成一个条目的练习的时候就向练习结果（临时表）写入数据
    - 练习完成后进入总结页面
- 如果是单词系列练习：
    - 选择练习的词种
        - 选项为数词，月份，代词，疑问词
    - 进行练习
        - 练习顺序是写死的，在规定位置填上固定的答案即可
        - 完成页面中所有练习的时候向练习结果（临时表）写入数据
    - 练习完成后进入总结页面
- 进入总结页面
    - 查看练习总结
        - 显示本次练习的结果
        - 显示过去练习的结果
        - 显示总体练习的结果
    - 导出练习结果，保存到本地（这里的练习结果包含两个功能的练习结果，包含选择的词库条目）
        - 这里要提示“练习结果不能保存到云端，只能保存在本地
        - 文件名为”【日期】.pracresult”
